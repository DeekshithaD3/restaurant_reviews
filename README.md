# Restaurant Review Analysis

## Overview

This project applies **Natural Language Processing (NLP)** techniques to analyze restaurant reviews and classify them as positive or negative. It involves data preprocessing, sentiment classification, and model evaluation.

## Features

- Data preprocessing (tokenization, stemming, stopword removal)
- Vectorization using **Bag of Words (BoW)** or **TF-IDF**
- Model training using machine learning algorithms (e.g., Naive Bayes, SVM, Random Forest, etc.)
- Performance evaluation using accuracy, precision, recall, and F1-score

## Dataset

The dataset consists of restaurant reviews labeled as **positive** or **negative**. It is preprocessed to remove noise, stopwords, and unnecessary characters.

## Model Training

The notebook trains a sentiment classification model using various machine learning techniques. It includes:

- Data cleaning and preprocessing

- Feature extraction using CountVectorizer or TF-IDF Vectorizer

- Model training and hyperparameter tuning

- Model evaluation using confusion matrix and accuracy score

## Conclusion

This project demonstrates the effectiveness of NLP in sentiment analysis and provides a framework for analyzing text-based customer feedback.
